# 42 NOS3 Multi-threaded IPC Patch

Targets stock NOS3 `nos3-main` branch of [nasa-itc/42](https://github.com/nasa-itc/42).

## Behavior

| Stock 42 | This patch |
|----------|------------|
| One blocking `accept()` per SERVER port during init | Detached pthread per SERVER port: `bind` → `listen` → `accept` loop |
| Init blocks until each port gets a client | Init returns immediately after all listener threads start |
| Single client per port; listen socket closed after first accept | Listen socket stays open; reconnecting clients get a fresh slot |
| Write/read errors crash the process (`exit(1)`) | Errors return gracefully; disconnected slots get recycled |

## Files

- `Source/42ipc.c` — Full replacement. Multi-threaded `InitInterProcessComm` + mutex-protected `InterProcessComm` + `SocketIsAlive` disconnect detection.

The `TxRxIPC.c` (autogenerated) is patched in-place by `apply_42_ipc_patch.py` (not a file overwrite) to:
- Add `if (Socket <= 0) return;` guards
- Replace `exit(1)` on write failure with `return`
- Catch `NumBytes == 0` (clean peer disconnect)

## Application

Applied by `scripts/cfg/apply_42_ipc_patch.py` during `make prep`. No changes to `iokit.c` or `iokit.h`.

## Config format

Uses the **standard** `Inp_IPC.txt` format (no AC.ID lines). Fully compatible with upstream `configure.py`.
